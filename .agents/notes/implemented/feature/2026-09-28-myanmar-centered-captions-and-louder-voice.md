# Agent Note: 解说字幕居中与旁白响度控制

## Problem

缅甸语解说字幕需要在原中文字幕模糊带内清晰呈现，且旁白响度需要独立调整，不能通过整体提高成片音量来实现。

## Decision

字幕渲染器支持 ASS 居中对齐值 5，并将字幕定位到画面与模糊字幕带中心。其他对齐方式保留原有行为。音频混音新增 `NARRATION_GAIN_DB`，只调整旁白轨；默认 0 dB，旁白与源音轨混合后继续使用最终限幅。

## Alternatives considered

- **继续使用底部小字幕** — 最强理由是可复用既有安全区；但不适合在已模糊的原字幕区域展示较大的译制字幕。
- **提高最终成片音量** — 最强理由是无需调整轨道结构；但会同时提高旁白间隙的源音，不能单独改善旁白相对响度。
- **在已烧录旧字幕的视频上叠加新字幕** — 最强理由是省去重渲染；但旧字幕仍会保留，因此应从干净源画面重建字幕层。

## Consequences

- **收益**：字幕可在模糊带中央展示，旁白响度可单独控制，仓库默认字幕位置和增益不变。
- **代价**：模糊带会模糊其覆盖区域的画面；提高旁白增益可能压缩动态，仍需对成片试听确认舒适度。

# Agent Note: 重用已认可的混音修复中段重排版听感

## Problem

中段画面顺序修正后的 v10 成片使用自建 Demucs 伴奏混音。用户反馈实际听感很差。既有混音笔记已记录 Demucs 可能产生水声或残余人声伪影；v10 又未加该方案要求的旁白窗口淡变，且只做了全片解码检查，没有主观试听。

## Decision

`recap_090181_myanmar_episodes_1-5_v11.mp4` 保留 v10 已核对过的画面、模糊带和字幕，但将音频改为从上一版试听认可的 `090181_myanmar_episodes_1-5_v9_480p.mp4` 提取完整混音。按 15 个原片段边界切分后，音频按画面对应的 `[0,1,2,3,4,5,6,9,10,7,8,11,12,13,14]` 顺序重排，旁白、原声避让和背景音的相对混音处理因此沿用 v9。压缩版为 `090181_myanmar_episodes_1-5_v11_480p.mp4`。两版时长约 329 秒，均通过全片解码检查。

## Alternatives considered

- **继续调低 v10 的 Demucs 伴奏音量** — 最强理由：不需要重新基于旧片段拼装音轨。否：伪影的听感已经被用户否定，单靠减小音量无法确认残影消失，也继续依赖未经认可的混音。
- **静音所有原片声音** — 最强理由：可以避免任何原片对白与缅甸语旁白重叠。否：之前用户要求旁白期间保留原片背景声音，整体静音会丢失环境氛围和音乐。

## Consequences

- **收益**：声音处理回到用户之前认可的混音，只改变与四段画面对应的时间顺序；避免重新分离对白和伴奏造成的新伪影。
- **代价**：v9 音轨已压缩，剪段后需要再次编码音频；本地系统完成了技术解码检查，但无法替代用户对最终听感的确认。

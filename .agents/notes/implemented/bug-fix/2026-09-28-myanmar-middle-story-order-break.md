# Agent Note: 缅甸语解说中段画面顺序倒叙造成跳接

## Problem

对照 `narration.json`、中文字幕与前五集源片关键帧后，中段 155–248 秒先剪入爷爷发现孩子并寻找线索的 ep4 画面，再剪回妈妈与孩子相处、孩子答数学题的 ep3 画面。旁白由发现转成母子内容，但没有明确回忆时间提示，形成故事时序倒退，源片片段与解说接不上。

## Decision

前五集重剪版 `recap_090181_myanmar_episodes_1-5_v10.mp4` 将片段与关联旁白按原片段编号重排为 `[0,1,2,3,4,5,6,9,10,7,8,11,12,13,14]`，剪辑时间映射记录在同目录的 `edit_plan_v10.json`。中段先放 ep3 的母子/数学片段（155–198 秒），再放 ep4 的爷爷发现/寻找片段（198–248 秒）。每段原素材的入出点和时长、缅甸语解说文本、Edge TTS 音频均保留，ASS 解说字幕按同一编号映射改时。总时长仍为 329 秒。

解说播出时原片声音静音、分离的无对白伴奏以 0.18 音量铺底；解说空隙恢复对应源片音轨至 0.70 音量。画面继续使用中央高斯模糊带承载放大的解说字幕。完整 1080×1920 成片与 480p 压缩版均完成全片解码；抽查了重排前后 10 个时间点。压缩版为 13,775,558 字节。

## Alternatives considered

- **只在旁白里增加“回到过去”等说明** — 最强理由：不改视频片段次序或剪辑时长。否：会让解说替反向剪辑解释，观众仍先知道爷爷寻找孙子再看到母子生活，不符合故事自然因果。
- **保持画面顺序不变，仅加转场效果** — 最强理由：减少对字幕/音频时间轴的改动。否：转场无法修复先后关系倒置，只会让倒叙更醒目。

## Consequences

- **收益**：先交代孩子的数学天赋和母子关系，再接爷爷发现相似并寻找线索；画面、旁白、字幕和原片声音使用同一重排顺序。完整与压缩文件都能全片解码。
- **代价**：需要全片重渲染，并重组与片段一一对应的原片声音和分离伴奏；没有增删剧情信息，只重排中段。人工抽查能确认代表帧和字幕存在，不等同于逐帧逐句审听。

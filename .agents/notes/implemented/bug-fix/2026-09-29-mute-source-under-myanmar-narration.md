# Agent Note: 缅甸语旁白期间默认静音原片混合音轨

Status: implemented

## Problem

缅甸语解说成片的原片音轨包含已配音对白、音乐和环境声。当前默认把原片声压到 12% 或 20%；`FOREIGN_SOURCE_AUDIO=1` 也只降到 5%，所以对白仍会与缅甸语旁白重叠。若没有可信的人声时间标记，整条混合音轨被视为背景声，导致重叠更难发现。既有逐片 Demucs 分离曾出现人声残影和音效伪影，不能当作稳定默认。

## Decision

缅甸语旁白默认在旁白窗口将原片混合音轨设为静音；旁白窗口外仍按 `IDLE_ORIG_VOLUME` 恢复原片。明确设置 `SPEECH_DUCKING_VOLUME` 或 `ZONE_DUCKING_VOLUME` 的用户仍可覆盖默认值。文档说明该默认牺牲旁白期间的原片音乐/环境声；需要保留氛围时，必须先单独分离人声与伴奏、试听确认无对白残影，再显式设置伴奏音轨，不能把低音量混合原片当作分离伴奏。

## Alternatives considered

- **继续把原片对白压到 5% 或 12%–20%** — 最强理由：可保留一部分配乐和环境氛围且不用额外素材。否：原片台词依然可听见，不能解决双语重叠投诉。
- **把 Demucs 人声分离设为每次默认** — 最强理由：理论上能在旁白下保留音乐和环境声。否：已有交付记录发现人声残影与水声等伪影，通用素材上的结果不可保证。

## Consequences

- **收益**：无 ASR 或重叠标签也不会把原片对白混入旁白；解说间隙仍能恢复完整原声；显式音量配置保持可用。
- **代价**：旁白期间原片音乐和环境声也一起静音；保留它们需要可靠的人声分离产物和人工试听。

# Agent Note: Edge TTS 双重变速

## Problem

Edge TTS 的速率参数已经提高语速，后续音频流程又执行一次 `atempo`，造成旁白听感发紧，并可能让配音与字幕时长不一致。音频流数量本身也不足以证明原片声音已被排除。

## Decision

缅甸语 Edge TTS 使用 `my-MM-ThihaNeural` 的原生 `+25%` 语速时，不再叠加 `atempo`、额外增益或 limiter。字幕结束时间跟随实际 TTS 音频时长。重建解说音轨时只映射视频流和独立旁白轨，不复用含原片对白的音轨；纯解说配置关闭源音频与背景音乐。

## Alternatives considered

- **保留第二次 `atempo`** — 最强理由是把语音压进旧字幕时间；但按实际生成的 TTS 时长延长字幕更自然，也避免重复加速。
- **只降低混合后原音音量** — 最强理由是可以沿用现有成片音轨；但无法证明原片对白不会漏进旁白段，因此从独立 TTS 音频重新构建旁白轨。

## Consequences

- **收益**：避免重复变速，旁白保持单一声源，原片对白不会从复用的源音轨混入纯解说版本。
- **代价**：字幕时间需要根据实际 TTS 时长生成；纯解说时关闭整条源音轨也会去掉与对白混在一起的音乐和音效。Edge TTS 需要网络连接。

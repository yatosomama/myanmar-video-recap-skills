# Agent Note: 缅甸语独立派生仓库说明

## Problem

将原项目的缅甸语改版发布到单独仓库时，需要让访问者一眼分清它与上游原版的关系，并说明改动范围和维护关系。

## Decision

中英文 README 顶部明确标记本项目为独立缅甸语改版，链接上游仓库，概述缅甸语 Edge TTS、中文字幕剧情参考和短剧剪辑流程，并说明本项目不是上游官方发布或背书。沿用原仓库 MIT 许可与归属说明。

## Alternatives considered

- **仅修改仓库名称，不说明来源** — 最强理由是改动少且标题能体现语言；但访问者仍无法判断与上游的关系及代码来源。
- **将改版内容合回上游仓库** — 最强理由是减少重复维护；但当前上游仓库写权限无法验证，因此采用独立仓库发布。

## Consequences

- **收益**：用户能区分原版与缅甸语改版，来源、主要改动和维护边界清楚。
- **代价**：独立仓库需要自行同步上游更新；README 声明不能自动同步许可证变更，后续仍要留意上游许可与归属要求。
